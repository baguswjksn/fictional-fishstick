Wikipedia di Xteink X4

1 November, 2026 · 2 menit

Xteink X4 itu e-reader kecil: layar e-ink 4,3 inci, resolusi 480×800, grayscale, dan RAM yang pas-pasan.

Aku pengen baca artikel Wikipedia di situ, tapi halaman Wikipedia dibuat buat browser. Tabelnya lebar, navigasinya banyak, dan gambarnya berwarna dalam macam-macam format.

Jadi aku bikin wiki2epub, script Python yang mengubah artikel Wikipedia jadi EPUB yang ringan dan rapi di X4.

Pakainya cukup kasih URL artikel: 

python -m pip install -r requirements.txt
python wiki2epub.py https://id.wikipedia.org/wiki/Borobudur

Bisa juga pakai judul artikel, atau beberapa URL sekaligus: 

python wiki2epub.py "Alan Turing" --lang en -o turing.epub
python wiki2epub.py URL1 URL2 URL3 --outdir buku/

Script-nya mengambil HTML artikel lewat API Wikipedia, lalu sisanya kerjaan bersih-bersih.

Navbox, tautan edit, style, dan skrip dibuang. Tautan ke halaman wiki lain dilepas dan tinggal teksnya, karena nggak bisa dibuka dari perangkat.

Infobox, kotak ringkasan di samping artikel itu, diratakan jadi paragraf biasa karena tabel lebar nggak muat di layar 480 piksel. Rumus matematika ditampilkan sebagai teks LaTeX.

Artikelnya lalu dipecah jadi satu file XHTML per bagian. File yang kecil berarti RAM lebih hemat dan pindah halaman lebih cepat.

Semua gambar diubah jadi JPEG grayscale baseline, maksimal 440×640 piksel. Harus baseline karena progressive JPEG, SVG, dan WebP nggak bisa diandalkan di X4. Kontrasnya juga disesuaikan otomatis, dan ikon yang terlalu kecil dilewati.

Terakhir, script-nya bikin sampul 480×800 berisi judul artikel, lalu menulis EPUB 3 dengan fallback NCX buat pembaca EPUB 2.

Ini hasilnya buat artikel Borobudur: 

Fetching [id] Borobudur ...
  14 chapters, 59 images -> Borobudur.epub (2132 KB)

HTML mentah dari API ukurannya 386 KB. Setelah dibersihkan, semua babnya tinggal sekitar 100 KB, dan begitu dikemas jadi EPUB tanpa gambar ukurannya 50 KB.

Sisanya datang dari 59 gambar tadi. Kalau kalian cuma butuh teksnya, tambahkan --no-images. Angkanya bisa beda kalau artikelnya sudah diedit.

Teks Wikipedia berlisensi CC BY-SA 4.0, jadi di akhir tiap EPUB ada catatan sumber lengkap dengan URL dan nomor revisinya.

Kodenya ada di GitHub, daftar opsi lengkapnya ada di README.

Script ini baru kubuat, jadi beberapa minggu ke depan bakal kucoba pakai dulu. Jangan kaget kalau masih ketemu bug.
