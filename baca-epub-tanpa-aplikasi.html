Baca EPUB tanpa Aplikasi

18 November, 2026 · 2 menit

Buat baca EPUB, biasanya harus pasang aplikasi dulu. Masalahnya, tiap perangkat butuh aplikasinya sendiri, dan pindah perangkat berarti cari aplikasi lagi.

Padahal hampir semua perangkat sudah punya browser. File EPUB sendiri itu ZIP biasa, isinya halaman HTML, gambar, dan beberapa file yang menjelaskan urutan bab.

Jadi aku bikin Plain EPUB Reader, pembaca EPUB dalam satu file HTML. Ini sebenarnya cuma fun project, biar aku bisa baca EPUB dengan gampang selama perangkatnya bisa buka browser.

Cara pakainya: buka index.html di browser, pilih file EPUB, lalu baca. Nggak perlu install apa-apa dan nggak ada library tambahan. HTML, CSS, dan JavaScript-nya semua ada di satu file itu.

Bukunya dibaca langsung di browser dan nggak dikirim ke mana-mana. Kalau file HTML-nya sudah ada di perangkat, semuanya jalan tanpa internet. Mau bisa dibuka dari mana aja, tinggal taruh file-nya di hosting statis kayak GitHub Pages.

Bacanya per halaman seukuran layar, kayak buku. Ketuk sisi kanan atau geser ke kiri buat halaman berikutnya, ketuk sisi kiri atau geser ke kanan buat mundur. Di laptop, pakai tombol panah, atau spasi buat maju.

Ketuk bagian tengah buat buka daftar bab dan ngatur ukuran huruf, dari 13 sampai 32 piksel. Garis tipis di bawah layar nunjukin sudah sejauh mana bukunya dibaca.

Posisi baca tiap buku dan ukuran huruf disimpan di browser. Besoknya tinggal pilih file yang sama, dan bukunya langsung kebuka di tempat terakhir dibaca.

Bikinnya juga nggak terlalu susah, soalnya EPUB itu cuma ZIP. Pembaca ZIP-nya kutulis sendiri, panjangnya sekitar 20 baris, dan isi yang terkompres dibuka pakai fitur bawaan browser. Setelah itu tinggal cari urutan babnya, lalu tampilkan satu per satu. Isi tiap bab itu halaman HTML biasa, dan nampilin HTML memang kerjaan browser.

Cara ini tentu ada batasnya. EPUB yang pakai DRM nggak bisa dibuka karena isinya terenkripsi. Tampilan bawaan buku juga dibuang, jadi semua buku pakai tipografi yang sama dan buku dengan tata letak khusus bakal kelihatan polos.

Fitur bawaan browser yang dipakai buat buka isi ZIP itu belum ada di browser lama, jadi butuh browser yang cukup baru. Satu lagi, file EPUB-nya sendiri nggak ikut disimpan, makanya harus dipilih lagi tiap mau baca.
