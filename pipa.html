Pipa

31 Juli, 2026 · 1 menit

INSERT INTO ternyata bisa diisi langsung dari hasil SELECT.

Bukan VALUES (...) yang kita tulis satu-satu, tapi INSERT INTO table SELECT ... FROM table_lain WHERE ...

Satu kalimat pendek, dan data pun pindah seolah nggak ada jarak di antara keduanya.

Dengan cara kerja seperti ini, kita nggak perlu mengaduk-aduk baris demi baris di memori.

Nggak ada variabel perantara yang nuggu.

Data cuma ngalir, lewat saringan WHERE, lewat persimpangan JOIN, lalu sampe di tujuannya sendiri.

Mungkin karena ini juga konsep kaya gini dinamain piping.

Kita nggak pernah liat data itu ngalir kayak air di pipa, tapi kita tahu dia lagi pindah dari satu titik ke titik lain.

Unix pipe juga begitu — cat file | grep | sort — satu proses serahin hasilnya ke proses berikutnya.

Konsep sesederhana INSERT INTO ... SELECT ini kerasa bener-bener menarik.

Nggak butuh framework, nggak butuh penjelasan panjang.
